# 手工验证检查清单（不可自动化行为）

动画手感、视觉连续性等无法用单元测试断言的行为，按本清单逐项人工验证。
**触发时机**：凡改动 `src/app.zig` 动画常量、`src/core/math.zig`、粒子/拖尾/渲染逻辑后，必须在 iOS 真机或模拟器上完整过一遍。

## 飞入与着陆

1. **飞入减速曲线** — 添加单个事件 → 心心从右上以背景流星的速度滑入，全程可感减速但保持流星般的滑移感，无「猛刹后爬行」的两段感。
2. **着陆过冲** — 心心到达落点时小幅冲过目标并果断回弹归位，无长时间振荡（约 0.5 秒内静止）。
3. **拖尾连续性** — 飞行全程拖尾为连续光带，无虚线断点、无点距疏密抖动；光带在屏幕边缘与背景流星一致地淡入，而非在边框处硬截断。
4. **轮廓流星联动** — 飞行轨迹穿过大心轮廓时，触发一次同向流星雨（比主心心慢且暗）。

## 批量与同步

5. **批量入场降级** — 日历全量同步（>3 个事件）→ 超出预算的心心直接淡入落点，不形成流星风暴；单个新增始终飞入。
6. **同步移除** — 删除日历事件 → 对应心心淡出消失，冷却粒子随之停止。

## 交互

7. **计数器轻拍脉冲** — 轻拍底部双心计数器 → 双心与天数文字同步短暂放大回弹，回调触发。
8. **心心点按** — 点按已着陆的事件心心 → 触发详情回调；密集簇中点按命中最近的一颗。
9. **快速添加** — 点右下角羽毛圆钮 → 输入胶囊铺满屏幕宽度（保留边距）展开并弹起键盘（不被遮挡）；键盘回车发送 → 胶囊收拢、心心从右上飞入、日历出现该事件（当前时间、无备注）；点空白处或下滑收键盘即取消；发送失败时草稿恢复。

## 状态变更

10. **Resize 重建** — 旋转设备/改变窗口 → 大心重建、已着陆心心按新布局重新同步，无残影、无轮廓缺口。
11. **主题过渡** — 切换主题（mint/peach/midnight/custom）→ 背景与心形颜色约 0.9 秒平滑渐变，无跳变。
12. **冷却粒子** — 新心心着陆后 2.5–4.5 秒内持续向下散落余烬并逐渐减弱至停止。

## 计数器

13. **天数计数** — 设置起始日后计数器逐位滚动递增；未设置时显示静态 `0.0000000000 DAYS`。
14. **天数文字点击** — 轻拍底部天数文字（含周围留白）→ 文字与双心同步短暂放大回弹并伴随轻触感，延迟片刻后弹出设置界面；文字区域外不误触发。

## 归档与回忆

15. **上限淘汰** — 累积超过 200 颗 tagged 心后，每颗新心着陆时最老的一颗平滑淡出（不归零、不闪切），屏幕密度稳定不再增长。
16. **回忆流星雨** — 归档非空后每隔 2.5–5 分钟，一小波（4–8 颗）更暗更小的心心以流星弹道飞入并驻留；下一波到来时，上一波平滑淡出。波形稀疏，不密集刷屏。
17. **归档对账** — 删除已归档事件的日历记录并触发同步后，该事件不再出现在后续回忆流星雨中。
18. **冷启动大量同步** — 通过主界面右上角「甲虫」压测面板（仅 DEBUG）造数后杀进程冷启动：UI 立即响应可交互，心心在数秒内分批渐进淡入，超过上限后最老者随之淡出，全程无冻结、无流星风暴。「生成 2000 心」用于快速回归；「写入日历 2000」用于全链路验证，验后用「清除日历压测」清理。

## 天空效果

19. **天空开关** — 设置 → 主题 → 天空开关：关闭时当前云约 1.2 秒淡出消失、无残留；打开时约 1.2 秒淡入，无闪切。
20. **天空自动轮换** — 开启状态下每 3–8 分钟（随机）当前云种淡出、另一种云种淡入；过渡平滑无跳变；长期观察五种云均应出现且不连续重复同一种。
21. **浓积云（轮换抽查）** — 穹顶状（顶部明亮蓬松、底部灰蓝扁平），轮廓簇生，右上银边、左下略暗；缓慢右移出屏回绕，透明度轻微呼吸。
22. **卷云（轮换抽查）** — 水平拉长的细丝/羽毛状云缕，弯钩卷曲、成束聚集；各条速度不同（风切变感），出屏回绕。
23. **荚状云（轮换抽查）** — 光滑透镜三层叠片（底大顶小），条纹随弧度弯曲、上亮下暗、边缘微虹彩；近乎驻定并缓慢浮动；编队两侧小积云与上方淡卷云点缀。
24. **层积云（轮换抽查）** — 多片云块交叠成毯、块间有缝、底部压暗、缝边银线，无接缝硬边；远近两层视差；重进模式各片疏密不同。
25. **积雨云（轮换抽查）** — 下窄上宽砧状云塔，花椰菜凸起、缝隙压暗、底部扁平灰暗；远层更小更暗更慢；无接缝硬边。
26. **云色主题跟随** — 切换主题后云色跟随主题（fill 亮部、stroke 暗部），过渡平滑。
